## ⚡ Princípios do Ecossistema

1. **Privacidade Pré-Inferência:** Nenhum prompt é enviado para LLMs externas antes de passar pelo sanitizador de PII.
2. **Compressão Semântica Extrema:** Algoritmos que enxugam o contexto preservando a instrução lógica, reduzindo custos e latência de processamento em 60%.
3. **Imunidade a Quedas e Limites de Cota:** O gateway detecta códigos HTTP 429 (Too Many Requests) em milissegundos e chaveia o fluxo para o próximo provedor compatível sem que a aplicação cliente quebre.
4. **Busca na Web Sem Rastreamento:** Integração de agentes com instância local de SearXNG rodando no próprio Proxmox VE.
